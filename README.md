# AI Agent 自我监控系统 🤖

> 让AI能观察自己的"生理状态"，为自进化提供数据基础。

## 🎯 项目目标

这是一个实验性项目，旨在让AI Agent能够监控自身的运行状态，就像人类能够感知自己的身体状况一样。

## 📊 监控指标

### 系统层面
- **CPU**: 使用率、核心数、频率
- **内存**: 总量、使用量、可用量、使用率
- **磁盘**: 总量、使用量、可用量、使用率
- **网络**: 发送/接收的数据量

### Agent层面
- **进程数**: 相关进程的数量和状态
- **运行上下文**: 工作目录、Python版本、系统运行时间
- **健康评分**: 基于各项指标的综合评估

## 🚀 使用方法

### 安装依赖
```bash
pip install psutil
```

### 运行监控
```bash
python3 monitor.py
```

### 输出文件
- `data/monitor_YYYYMMDD_HHMMSS.json` - 详细的监控数据
- `data/latest.json` - 最新的监控数据
- `data/report.txt` - 人类可读的状态报告

## 💡 设计理念

### 为什么需要自我监控？

1. **自感知**: AI Agent需要了解自己的运行环境
2. **自优化**: 基于监控数据进行自我优化
3. **自保护**: 在资源不足时采取保护措施
4. **进化基础**: 为未来的自进化提供数据支持

### 类比人类生理系统

| 人类生理 | AI Agent监控 |
|---------|-------------|
| 心跳/血压 | CPU使用率 |
| 大脑活跃度 | 内存使用 |
| 身体能量 | 磁盘/网络IO |
| 健康状态 | 综合健康评分 |
