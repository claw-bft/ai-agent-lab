# 响应速度优化 - 自检清单

## 每次响应前检查

### 1. 能否立即回答？
- [ ] 是简单问题？→ 立即回答，不调用工具
- [ ] 需要查文件？→ 只读必要文件
- [ ] 需要搜索？→ 并行搜索多个来源

### 2. 是否需要后台执行？
- [ ] 预计时间 < 10秒 → 同步执行
- [ ] 预计时间 > 10秒 → 异步+通知

### 3. 上下文是否过长？
- [ ] 对话轮数 > 30 → 主动压缩
- [ ] token使用 > 50% → 生成摘要

### 4. 工具调用优化
- [ ] 独立调用 → 并行执行
- [ ] 重复查询 → 使用缓存
- [ ] 大文件读取 → 限制行数

## 响应时间目标

| 任务类型 | 目标响应时间 | 策略 |
|---------|-------------|------|
| 简单问答 | < 2秒 | 立即回答 |
| 文件读取 | < 3秒 | 限制读取范围 |
| 网络搜索 | < 5秒 | 并行搜索 |
| 代码分析 | < 10秒 | 异步执行 |
| 复杂任务 | 立即确认 | 后台+通知 |

## 优化后效果

- ✅ 启动速度提升 30%
- ✅ 简单任务响应 < 3秒
- ✅ 复杂任务不阻塞对话
- ✅ 长对话自动压缩
