# Changelog

All notable changes to the Agent Collaboration Protocol project will be documented in this file.

## [1.0.0] - 2026-03-01

### Added
- Initial release of Agent Collaboration Protocol (ACP)
- Core protocol implementation with message bus and agent registry
- Support for multiple collaboration modes: negotiation, voting, delegation
- Predefined workflows for stock research and product development
- CLI tool for managing agents and workflows
- Comprehensive test suite with 29 tests
- Performance benchmarks for all major components

### Features
- **Agent Registry**: Dynamic discovery and management of agents
- **Message Bus**: High-performance message passing (point-to-point and broadcast)
- **Task Orchestrator**: Support for sequential, parallel, and conditional execution
- **Result Aggregator**: Intelligent merging of multi-agent results with conflict resolution
- **Negotiation Manager**: Multi-agent negotiation and proposal management
- **Voting Manager**: Support for 4 voting types (majority, unanimous, weighted, ranked)
- **Delegation Manager**: Permission delegation and proxy execution

### Documentation
- Added comprehensive README.md
- Added SKILL.md with usage examples
- Added API documentation

## [0.9.0] - 2026-02-28

### Added
- Beta release with core functionality
- Basic agent communication protocol
- Simple task orchestration
