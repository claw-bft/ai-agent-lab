## 📦 部署包内容

- `README.md` - 项目说明

## 🚀 部署方式

### 方式一：Vercel 手动部署（推荐）

1. 访问 https://vercel.com/new
2. 选择 "Import Git Repository" 或 "Upload"
3. 上传 `deploy-20260302-0356.tar.gz` 文件
4. 点击 "Deploy"

### 方式二：Netlify 部署

1. 访问 https://app.netlify.com/drop
2. 拖拽 `index.html` 文件到上传区域
3. 获得访问链接

### 方式三：Cloudflare Pages

1. 访问 https://dash.cloudflare.com/
2. 创建新 Pages 项目
3. 上传 `index.html` 文件

### 方式四：GitHub Pages

1. 创建新 GitHub 仓库
2. 上传 `index.html` 文件
3. 启用 GitHub Pages
