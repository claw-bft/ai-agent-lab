# 快速任务模板

预定义的常用任务，用户可以快速调用。

## 模板列表

### 1. 早报生成
**触发词**: `早报` / `morning report`
**功能**: 生成股市早报
**参数**: 无
**示例**: 
```
用户: 早报
我: 立即执行早报生成任务...
```

### 2. 股票分析
**触发词**: `分析股票` / `analyze stock`
**功能**: 分析指定股票
**参数**: 股票代码或名称
**示例**:
```
用户: 分析股票 000001
我: 分析平安银行...
```

### 3. 网页部署
**触发词**: `部署` / `deploy`
**功能**: 部署项目到Vercel
**参数**: 项目路径
**示例**:
```
用户: 部署 /path/to/project
我: 开始部署...
```

### 4. 网络搜索
**触发词**: `搜索` / `search`
**功能**: 搜索网络信息
**参数**: 搜索关键词
**示例**:
```
用户: 搜索 最新AI新闻
我: 搜索中...
```

### 5. 代码审查
**触发词**: `审查代码` / `code review`
**功能**: 审查代码文件
**参数**: 文件路径
**示例**:
```
用户: 审查代码 /path/to/file.py
我: 开始代码审查...
```

### 6. 任务状态
**触发词**: `状态` / `status`
**功能**: 查看当前任务状态
**参数**: 无
**示例**:
```
用户: 状态
我: 当前有3个任务运行中...
```

### 7. 帮助
**触发词**: `帮助` / `help`
**功能**: 显示可用模板列表
**参数**: 无

## 实现方式

1. **关键词匹配**: 检测用户输入的前几个词
2. **参数提取**: 解析后续内容作为参数
3. **快速执行**: 直接调用对应技能，无需完整描述

## 使用示例

用户输入: `早报`
→ 匹配模板1
→ 执行早报生成任务
→ 完成后主动通知

用户输入: `搜索 OpenClaw最新动态`
→ 匹配模板4
→ 参数: "OpenClaw最新动态"
→ 执行网络搜索
→ 返回结果
