# Product Pro 技能包

## 功能模块

### 1. 市场与竞品研究
- 深度市场情报收集
- 竞品全面对比分析
- 用户心理洞察与行为经济学
- 行业报告与专利数据库检索

### 2. 产品文档与表达
- PRD/MRD/BRD专业撰写
- 智能PPT生成与视觉设计
- 第一性原理问题拆解
- 需求一致性检查

### 3. 数据驱动决策
- 用户行为数据分析
- A/B测试设计与分析
- 增长指标监控
- 产品健康度评估

## 依赖工具
- tavily-search (实时搜索)
- deepresearch (深度研究)
- data-analyzer (数据分析)

## 使用示例

```bash
# 竞品分析
product-pro competitor analyze --product "AI代码助手" --output report.md

# 撰写PRD
product-pro prd create --feature "智能代码补全" --template standard

# 生成PPT
product-pro ppt create --topic "Q4产品规划" --slides 15

# 用户调研
product-pro research conduct --method interview --target "开发者" --n 20

# 数据分析
product-pro analytics dashboard --metrics DAU,retention,conversion
```
