# Legal Assistant - 法律助手

## 描述
专业法律文档分析和咨询服务，支持合同审查、法规查询、案例检索。

## 功能

### 1. 合同审查
- 风险条款识别
- 权利义务分析
- 违约责任检查
- 建议修改方案

### 2. 法规查询
- 法律法规检索
- 司法解释查询
- 地方法规检索
- 最新政策追踪

### 3. 案例检索
- 相似案例匹配
- 判决结果分析
- 法官观点提取
- 胜诉率预测

## 使用示例

```bash
# 审查合同
legal-assistant review --file contract.pdf --type employment

# 查询法规
legal-assistant search --keyword "劳动合同法" --article 38

# 案例检索
legal-assistant cases --subject "劳动争议" --court "北京"
```

## 依赖
- 法律数据库API
- 自然语言处理
- 文档解析引擎
