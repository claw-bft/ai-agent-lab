# OpenClaw 控制面板 (OpenClaw Dashboard)

## 项目概述
为 OpenClaw 设计的可视化交互系统，替代命令行对话方式。

## 核心功能

### 1. 任务管理模块
- 可视化任务列表（进行中/已完成）
- 任务详情展示（来源、状态、进度）
- 快速添加/编辑任务
- 任务优先级标记

### 2. 技能管理模块
- 已安装技能网格展示
- 技能搜索/筛选
- 一键安装新技能
- 技能使用统计

### 3. 交互模块
- 对话式界面（替代当前命令行）
- 文件上传/下载
- 实时状态显示
- 历史记录浏览

### 4. 系统监控
- 运行状态监控
- 资源使用统计
- 日志查看器

## 技术栈
- React + TypeScript
- Tailwind CSS
- shadcn/ui 组件库
- WebSocket 实时通信

## 部署
使用 Vercel 一键部署
